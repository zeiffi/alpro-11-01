Introduction
algoritma: menghitung volume lemari baju
langkah langkahnya:
1. ambil penggaris untuk mengukur panjang lemari
2. catat hasilnya dengan menggunakan pensil di kertas
3. pakai penggaris untuk mengukur lebar lemari
4. catat hasilnya dengan mengginakan pensil di kertas
5. pakai penggaris untuk mengukur  tinggi lemari
6. catat hasilnya dengan menggunakan pensil di kertas
7. hitunglah hasil dari panjang x lebar x tinggi
8. catat hasilnya
